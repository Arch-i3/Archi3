Telepitesi Utmutato

USB Telepito Letrehozasa (BalenaEtcher)

1

Toltsd le a BalenaEtcher-t

Latogass el a balena.io/etcher oldalra es toltsd le a rendszerednek megfelelo verziot.

2

Valaszd ki az ISO fajlt

Kattints a "Flash from file" gombra es valaszd ki a letoltott Pure de Arch ISO fajlt.

3

Valaszd ki az USB meghajtat

Kattints a "Select target" gombra es valaszd ki az USB meghajtodat. Figyelj, hogy a megfelelo eszkoz legyen kivalasztva!

4

Indits el az irast

Kattints a "Flash!" gombra es vard meg, amig az iras es ellenorzes befejezodik.

WM Alkalmazasok Telepitese

A kovetkezo parancsokkal telepitheted a legnepszerubb alkalmazasokat Window Manager kornyezethez:

1

Alacritty (Terminal Emulator)

Gyors, GPU-gyorsitott terminal emulator

sudo pacman -S alacritty
2

Thunar (File Manager)

Konnyen hasznalhato grafikus fajlkezelo

sudo pacman -S thunar
3

mpv (Media Player)

Konnyu es sokoldalú medialejatszo

sudo pacman -S mpv
4

Firefox (Web Browser)

Nepszeru, adat vedelemre fokuszalo bongeszo

sudo pacman -S firefox

Minden egyszerre

Az osszes alkalmazas egyetlen paranccsal:

sudo pacman -S alacritty thunar mpv firefox
